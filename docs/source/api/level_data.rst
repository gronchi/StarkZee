level_data, fac_reader, cowan_reader
====================================

The neutral J-level data model and the readers that fill it from FAC tables
and Cowan RCG output. Reduced elements are stored as
:math:`\langle \mathrm{lower}\|d\|\mathrm{upper}\rangle` in the Edmonds
convention, and each one records whether its sign came from the source.
