profile_table
=============

Static profiles at many densities and temperatures from one set of dressed states:
the Hamiltonian depends on the plasma only through the microfield, so the
eigensystems on a fixed field grid serve every density.

.. automodule:: starkzee.profile_table
   :members: StaticProfileTable

The microfield weights on the table's field grid come from
:func:`starkzee.microfield.microfield_weights`.
