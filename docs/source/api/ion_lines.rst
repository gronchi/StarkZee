single_valence, he_i
====================

Ready-made radiators from NIST data. They cover one-valence-electron ions
(Li-like C IV, N V and O VI n = 5 → 4, or any line from a level table) and
He I 447.1 nm with its Stark-mixed n = 4 triplet manifold; ``singlets=True``
adds the singlet terms with the spin-orbit singlet-triplet coupling of the 4d
and 4f J = L pairs fitted to the NIST levels.
