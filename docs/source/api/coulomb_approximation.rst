coulomb_approximation
=====================

Signed radial integrals :math:`\langle n^*l|r|n^{*\prime}l'\rangle` and
:math:`\langle n^*l|r^2|n^{*\prime}l'\rangle` in the Coulomb approximation of
Bates and Damgaard (1949). They are exactly hydrogenic for integer :math:`n^*`.
