Convergence diagnostics
=======================

The green regression suite checks implementation contracts; it is not a
universal convergence or physical-accuracy certificate. Profile calculations
must be converged for the requested transition, plasma conditions, spectral
window, and observable.

The repository includes ``scripts/profile_convergence.py``. Its representative
H-alpha report independently varies field and angle quadrature, microfield
cutoff, energy-grid resolution, energy window, and (for FFM) SDT binning. It
also reports the effect of enabling each solver's supported Doppler path and,
when both solvers are selected, compares static and FFM profiles with matched
exposed controls both before and after Doppler broadening:

.. code-block:: powershell

   python scripts/profile_convergence.py --solver both --output convergence.json
   python scripts/profile_convergence.py --solver both --full --output convergence_full.json

The report contains total and polarization-resolved areas, centroid and peak,
relative area and centroid changes, overlap-domain L1 and peak-normalized
L-infinity shape errors, and the fraction of reference area covered by a
candidate window. For intrinsic and Doppler-enabled reference profiles it also
transforms per-eV component densities to vacuum wavelength (per nm), frequency
(per THz), and wavenumber (per cm\ :sup:`-1`) and reports their finite-grid
area-conservation errors. It deliberately supplies no pass/fail threshold.
The representative case declares five intensity samples relative to line
center: blue/red wings at :math:`\pm0.008` eV, blue/red core points at
:math:`\pm0.002` eV, and line center. Every comparison reports interpolated
total and polarization-component intensities plus absolute and relative
differences at those points; sampling outside the common window is rejected.

The Doppler comparison is a physical sensitivity report, not a convergence
error. Static constant-width components use the in-solver Voigt path, while
FFM applies Doppler after its nonlinear transformation. The diagnostic does
not implement or validate the alternative ZEST placement inside the
construction of :math:`J`; those operations need not commute.

For application validation, copy or extend the diagnostic with the actual
transition and plasma regime, refine more than one parameter at a time after
the one-at-a-time scan, and declare acceptance tolerances before interpreting
the result. At least one comparison should use an external calculation or
measurement not generated by StarkZee.

The metric functions are also reusable directly:

.. code-block:: python

   from starkzee.validation import (
       compare_profiles, coordinate_jacobian_metrics, profile_metrics,
   )

   metrics = profile_metrics(energy_ev, (pi, sigma_plus, sigma_minus))
   delta = compare_profiles(reference_energy, reference_components,
                            candidate_energy, candidate_components,
                            sample_energies_ev=selected_energies)
   jacobians = coordinate_jacobian_metrics(
       reference_energy, reference_components)

Exact hydrogenic charge scaling
--------------------------------

For the nonrelativistic Coulomb Hamiltonian without fine structure or magnetic
terms, the coordinate transformation :math:`\boldsymbol{\rho}=Z\mathbf r`
gives

.. math::

   H(Z,F)=Z^2 H(1,F/Z^3),

while electric-dipole matrices scale as :math:`1/Z`. The regression suite
checks this identity for the production intra-shell Stark matrices, their
linear-Stark eigenvalue spectra, and all three radiative polarization matrices
at :math:`Z=2,6,18`. The full shell Hamiltonian is deliberately excluded:
``fine_structure=False`` suppresses mass-velocity and Darwin corrections but
retains the separately implemented spin-orbit term. These tests validate the
exact hydrogenic scaling of the nonrelativistic operators; they do not validate
relativistic/QED energies, charged-emitter microfields, or the electron-
collision model for highly charged ions.

Ar XVII manual benchmark
-------------------------

The PPP manual's four-level Ar XVII example provides a compact check at
:math:`Z=18`. StarkZee's present :math:`O((Z\alpha)^4)` Hamiltonian reproduces
the manual's :math:`2p_{3/2}-2p_{1/2}` interval within 2%, but its absolute
excitation energies are about 0.9--1.0 eV high. It has no Lamb correction and
therefore retains the Dirac :math:`2s_{1/2}=2p_{1/2}` degeneracy; the manual's
levels differ by 0.167725 eV. The regression records this as a known model
boundary, not as agreement with the missing QED physics.

The J-coupled nonrelativistic reduced dipoles agree with the four manual values
within 2%. Their individual signs depend on level phases: rephasing the
:math:`2s_{1/2}` state maps StarkZee's positive-near-origin radial convention
onto the manual's all-negative table. The phase-invariant product around the
closed four-transition loop agrees in both conventions.
